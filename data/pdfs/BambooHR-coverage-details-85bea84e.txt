Employee tables
Backup
“Dependent” tables (e.g., benefits table) cannot be backed up in this iteration as support
for “benefits” is not included in this release.
Restore
- Only an entire table can be selected for restore. Individual rows cannot be
restored.
- Hard-restore logic applies to this entity. Table rows that exist in the organization
in BambooHR but not in the snapshot are deleted.
- The order in the tables is determined by the ID field. Therefore, it might be
difficult to predict which row will be the most recent if the date value of any row
has changed.
- Rows from the Job Information table that exist only in BambooHR but not in the
snapshot are not deleted during restore (Invalid permissions error).

Company fields
Restore
We do not support the restoration of standalone fields.

 Termination Type
 Eligible For Re hire
