Restore Zendesk data
Items are restored in place to their original locations.
Restore a Zendesk item
1. In your connector, find the item you want to restore.
Note: To restore multiple items at a time, select the items. In the toolbar, select Restore.
2. Optional: If you want to restore an item from an earlier point in time, select the Snapshots Viewer, and then select the appropriate snapshot.
3. Point to the item and click ••• > Restore.
4. Select Yes to restore the item.
