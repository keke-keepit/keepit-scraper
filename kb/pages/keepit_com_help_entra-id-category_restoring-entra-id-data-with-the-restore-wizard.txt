Restoring Entra ID data from the connector level
If you need to bring back a significant amount of Entra ID data, restore from the connector level. This allows you to restore all groups, users, administrative units, roles, service principals, app registrations, and policies simultaneously.
We recommend restoring all objects together to ensure that relationships between them are fully recreated.
Restore Entra ID data
1. Open the Connectors page.
2. Point to the connector and click the Restore icon.
3. Select Restore to same location and click Next.
4. Select the desired snapshot.
5. Select the folders you want to restore and click Next.
6. Review the summary and click Restore.
Restoring to a different tenant
Restoring from the connector level, you can recover Microsoft Entra ID objects into a different tenant while automatically preserving object relationships and dependencies. For more information, see: Restore Entra ID data to a different tenant
Important: Restoring service principals
Service principals cannot be restored if their corresponding app registrations are missing from the tenant. To ensure all service principals are successfully restored, we recommend restoring them alongside their related app registrations.
If the app registration linked to a service principal belongs to a different tenant, the service principal will still be restored, even if the app registrations folder is not included in the restore.
