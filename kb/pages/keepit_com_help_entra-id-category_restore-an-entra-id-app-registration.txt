Restore an Entra ID app registration
Restoring an app registration will update basic information about the application and reestablish links to its owners.
Restore an app registration
1. In your connector, find the app registration you want to restore.
2. (Optional) To restore an item from an earlier point in time, open the Snapshots Viewer and select the appropriate snapshot.
3. To the right of the item, click ••• > Restore.
4. Click Yes to restore the item.
What happens when an app registration is restored
Attributes and basic information restored
Attributes, basic information about the application (Essentials in the overview), and the data in the sections Branding & properties, Authentication, and App roles are restored.
Relationships reestablished
The following relationships are reestablished:
- Owners — links to users who are owners of this app registration will be restored.
Note: A relationship can be reestablished only if the linked object still exists in Entra ID. 
New ID and creation time
- If the app registration was recently deleted (it remains in a suspended state for 30 days), Keepit restores it with its original ID and creation time. The deletion time property changes to null.
- If the app registration was permanently deleted, Keepit restores it with a new ID and creation time.
Limitations
Due to an API limitation, Keepit doesn't back up or restore data in Certificates & secrets unless the connector has an Azure Key Vault instance connected. For details on how Keepit handles secrets and certificates during a restore, see Application and service principal restores.
