Restore an Entra ID object's licenses
Restoring a user's or group's licenses will assign the licenses to the user or group.
You can restore an entire licenses folder or individual licenses.
Restore an object's licenses
1. Locate the folder inside the object.
2. (Optional) To restore an older version, select the Snapshots Viewer icon and select an earlier snapshot. You are now viewing data from that point in time.
3. Select ••• > Restore.
4. Select Yes to confirm.
Note: If the user doesn't have a valid usageLocation value set, Microsoft Graph blocks the license reassignment. The Graph API requires this attribute before licenses can be assigned. For more information, see Microsoft documentation.
