Create an Okta connector
Before creating your connector, you must first add an app integration in Okta. During this process, you will also obtain the organization host, application ID, and application secret—all of which are required to complete the connector setup.
For details on how to create an app integration, go to: Configure an Okta app integration
Preparation
Obtain your organization host
Your Okta organization host can be found in one of two ways:
1. From the URL of your Okta organization
Use the base domain of your Okta URL — do not include the -admin suffix.
- â Example of a valid host: dev-12345678.okta.com
- â Example of an invalid host (with -admin suffix): dev-12345678-admin.okta.com
2. From the user context menu
You can also retrieve the organization host from your app integration by opening the user context menu and copying the host from there.
Note: In the examples above, the dev prefix indicates a developer account. If you're not using a developer account, your host will not include this prefix.
Obtain your application ID and application secret
You can obtain the application ID and application secret from your app integration.
- For the Application ID:
 In the Client Credentials section, click the copy button next to the Client ID field.
- For the Application Secret:
 Scroll down to the Client Secrets section, and click the copy button next to the secret value.
