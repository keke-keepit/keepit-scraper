Create an Okta connector
Before creating your connector, you must add an app integration in Okta. During this process, you also obtain the organization host, application ID, and application secret — all required to complete the connector setup.
For instructions, go to: Configure an Okta app integration
Preparation
Obtain your organization host
Your Okta organization host is available in two ways:
From the URL of your Okta organization
Use the base domain of your Okta URL. Don't include the -admin suffix.
- â Example of a valid host: dev-12345678.okta.com
- â Example of an invalid host (with -admin suffix): dev-12345678-admin.okta.com
From the user context menu
Open the user context menu in your app integration and copy the host from there.
Note: The dev prefix in the examples above indicates a developer account. If you're not using a developer account, your host won't include this prefix.
Obtain your application ID and application secret
You can find both values in your app integration:
- For the Application ID:
In the Client Credentials section, click the copy button next to the Client ID field.
- For the Application Secret:
In the Client Secrets section, click the copy button next to the secret value.
