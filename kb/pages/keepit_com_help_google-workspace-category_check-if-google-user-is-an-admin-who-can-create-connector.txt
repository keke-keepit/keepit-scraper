Check if Google user is an Admin who can create connector
Sign in to http://admin.google.com/ with your Google admin credentials.
- If you are still on http://admin.google.com/ and can see the admin panel, then your Google user is an administrator who can create a Google Workspace connector.
- If you are redirected to https://apps.google.com/user/hub and can see the Your apps panel, then your Google user is a regular user who cannot create a Google Workspace connector.
