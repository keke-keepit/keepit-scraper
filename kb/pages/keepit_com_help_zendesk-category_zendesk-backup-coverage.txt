Zendesk backup coverage
Keepit backs up the following Zendesk data:
Required data coverage
Tickets
- Ticket comments and attachments
- Ticket fields (custom and standard)
- Ticket forms
- Archived tickets
Users
- Team members
 Group memberships
 Organization memberships
 Organization subscriptions
 Personal views
Personal macros
- End users
Organization memberships
- User fields
Groups and Organizations
- Members
- Subscribers
- Organization fields
Optional data coverage
Views
- Shared views
Macros
- Shared macros
Triggers
Automations
