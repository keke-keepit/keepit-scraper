Can I still use my Keepit credentials after setting up SSO?
Yes, you can continue using your Keepit username and password to sign in, even after setting up SSO. However, to use your Keepit credentials, you must disable the Make SSO mandatory option in the SSO configuration. When disabled, you'll be prompted to choose between signing in with your Keepit credentials or SSO each time you log in.
Please note that if SSO is not mandatory, you won’t fully benefit from the security and convenience advantages that SSO offers.
We recommend creating an SSO Admin role when setting up SSO. This user can sign in using their Keepit credentials, even if SSO is made mandatory. The SSO Admin role provides access only to the SSO configurations, not to user data. By creating this role, you can make SSO mandatory but always have a backdoor into the configuration in case SSO is misconfigured or the SSO certificate expires.
